## AgendAI 会小纪 0.1.4

本版本优化全局界面交互和会议纪要阅读体验。

### 界面与交互

- 会议侧边栏支持搜索会议标题、状态和采集来源。
- 会议列表增加右键菜单，可快速打开或归档会议。
- 会议详情页将标题保存操作移至 macOS 工具栏。
- 会议状态、空内容和缺失信息采用更明确的系统化呈现。

### 结构化会议纪要

- 原始纪要从等宽 Markdown 文本改为结构化文档视图。
- 新增会议概览、摘要、议程、讨论过程、结论、未决事项、待办和时间节点分区。
- 议题支持折叠/展开，待办和未决事项显示负责人、时间节点及状态。
- 地点无可靠来源时显示“未记录”，未决事项责任人和时间无可靠来源时显示“待确认”。
- Markdown 与 HTML 导出同步使用新版内容结构。

### 兼容性与验证

- 保留历史会议纪要缓存读取能力。
- 未修改 AI 分析提示词、会议纪要生成提示词或 Agent 执行链路。
- 通过 534 个 Swift 测试、macOS 构建和发布包检查。

当前发布包使用本地 ad-hoc 签名，尚未使用 Apple Developer ID 或公证。首次打开时，macOS 可能要求右键选择“打开”，或在“系统设置 → 隐私与安全性”中确认。
